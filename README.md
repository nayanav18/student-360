# Student 360 🎓

**Student 360** is a personalized academic and campus companion web application for college students. It provides a unified command center to understand:

- 📊 **Academic Progress & Performance**: CGPA progression, course-wise marks, CIA scores, and semester analytics.
- 📅 **Academic Calendar**: Compact monthly calendar displaying classes, assignments, exams, workshops, competitions, and personal tasks directly inside date cells.
- 🕒 **Today's Schedule & Attention Needed**: Real-time alerts for impending deadlines, low attendance warnings (<75%), and class schedules.
- 📝 **My Plan**: Personal task planner with auto-filled date/time for continuous batch entry and deletion confirmations.
- 📚 **Courses & Attendance**: Compact course cards with syllabus viewer and real-time attendance margin calculations.
- 📄 **Assignments**: Priority-sorted assignment cards with status filters and rich submission/detail modals.
- 🏛️ **Campus Discovery**: Featured event spotlight with continuous left-sliding carousel, event filters, and contextual audition/participation registration.
- ✍️ **My Notes**: Complete rich-text document workspace with formatting tools, image insertion, custom tables, and CTA buttons.

---

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animation**: [GSAP](https://greensock.com/gsap/)
- **Typography**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
- **State & Storage**: React Context + Custom `useLocalStorage` hook

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/nayanav18/student-360.git
cd student-360
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open `http://localhost:5173` (or the port indicated in your terminal) in your browser.
